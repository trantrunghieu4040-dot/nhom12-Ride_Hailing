## Các màn hình đã thiết kế

### 📱 Ứng dụng Khách hàng (Customer App)
- [x] Splash Screen
- [x] Login / Register (xác thực OTP)
- [x] Home — Đặt xe (nhập điểm đón/trả, chọn loại xe)
- [x] Booking Confirmation — Xác nhận giá cước & đặt xe
- [x] Tracking — Theo dõi tài xế realtime trên bản đồ
- [x] Payment — Thanh toán (Tiền mặt / MoMo / VNPay)
- [x] Review & Rating — Đánh giá 1–5 sao
- [x] Profile — Quản lý hồ sơ cá nhân

### 🚗 Ứng dụng Tài xế (Driver App)
- [x] Login
- [x] Trip Receive — Nhận/từ chối chuyến xe
- [x] Navigation — Dẫn đường đến điểm đón/trả
- [x] Income — Thống kê thu nhập theo ngày/tuần/tháng

### 🖥️ Dashboard Quản trị viên (Admin Web)
- [x] Login
- [x] Dashboard — Tổng quan hệ thống
- [x] Driver Approval — Phê duyệt hồ sơ tài xế
- [x] User Management — Quản lý Khách hàng & Tài xế
